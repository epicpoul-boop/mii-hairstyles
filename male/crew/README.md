# Crew — short military cyberpunk plate

Low hemispheric cap shell — almost full top, short even hem (slightly above ear line), sharp flat brow hairline.

## Design
- Single continuous thick shell (meridian grid + Solidify **0.16**)
- Even hem ~**z=0.02–0.08** (unpitched); pitch **-8°**
- Polygonal hairline: Z_BROW=0.58 → Z_TEMPLE=0.42; face open ±42°
- Glossy near-black plastic; unit sphere r=1; OBJ Y-up
