# Spike — short cyberpunk geometric spikes

Short base cap + **5** thick wedge/prism spikes — minimal toy plates, not realistic hair.

## Design
- Base: short shell (Solidify **0.15**, slight flat top)
- Spikes: solid tapered rectangular wedges, forward-leaning
- Glossy near-black plastic; unit sphere r=1; OBJ Y-up

```bash
blender -b -P scripts/generate_spike.py
```
