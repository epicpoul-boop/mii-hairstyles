# Undercut — flat-top cyberpunk plate

Thick flattened top plate with high hem (bare sides). Sharp geometric silhouette.

## Design
- Flattened crown (**flat_top≈0.92**) + Solidify **0.19**
- High even hem ~**z=0.42–0.48** — sides essentially bare
- Angular brow hairline; pitch **-4°**
- Glossy near-black plastic; unit sphere r=1; OBJ Y-up

```bash
blender -b -P scripts/generate_undercut.py
```
