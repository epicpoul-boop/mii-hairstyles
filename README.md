# Mii hairstyles (extracted)

Extracted hairstyle meshes from Joey Carlino’s free **Mii Maker for Blender**:
https://joeycarlino.gumroad.com/l/mii

## Contents
- `mii_hairstyles_only.blend` — 131 hair style meshes
- `meshes/hair.XXX.obj` — individual OBJ exports
- `meshes/all_hairstyles.obj` — combined
- `textures/hair_sprite.png`
- `manifest.json` — index
- `mii-hairstyles-pack.tar.gz` — full archive (if present)

## Attribution
Original project © Joey Carlino (Gumroad, free). This repo only redistributes extracted hair meshes for personal/dev use (e.g. AI Studio). Respect the creator’s terms for commercial reuse.
