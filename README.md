# mii-hairstyles

Minimal cyberpunk plastic-plate hairstyles for a round unit-sphere head (radius 1).
OBJ Y-up. Scale by `headRadius / 1.0` if your head isn’t unit size.

## Styles

### Bobcut
Longer A-line bob — single continuous glossy shell.
- `bobcut/bobcut.obj` (+ `.mtl`, `.blend`)
- `bobcut/previews/` — hair alone
- Raw: `https://raw.githubusercontent.com/epicpoul-boop/mii-hairstyles/main/bobcut/bobcut.obj`
