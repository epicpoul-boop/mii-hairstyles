# Pixie — short polished cyberpunk plate

Cropped nape/sides, slightly fuller crown, sharp angular bangs — still hyper-minimal plate language.

## Design
- Short even-ish hem front **0.18** / nape **0.38** (tight crop)
- Angular bangs: Z_BROW=0.58 → Z_TEMPLE=0.30; face open ±46°
- Fuller crown (outer **1.22**, light flat_top); Solidify **0.17**; pitch **−10°**
- Glossy near-black plastic; unit sphere r=1; OBJ Y-up

blender -b -P scripts/generate_pixie.py
