# Twin buns — cyberpunk cute discs

Two thick spherical/disc buns above the temples on a smooth short shell base. Few shapes, toy-like, plate-minimal.

## Design
- Base: short shell (Solidify **0.16**, slight flat crown, cropped hem)
- Buns: 2 squashed UV-spheres (r≈0.30, Z-squash 0.78) above ±temples
- Glossy near-black plastic; unit sphere r=1; OBJ Y-up

```bash
blender -b -P scripts/generate_twin_buns.py
```
