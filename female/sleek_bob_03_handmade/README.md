# Sleek Bob 03 — Handmade (Tripo-guided)

Hand-modeled by André in Blender, using the Tripo image-to-3D model as a shape guide.
Shrinkwrapped UV-sphere shell (thickened) plus four smooth bang pieces, joined into one object.

- Head: sphere radius 0.5 at origin (chibi scale), face toward −Y in Blender (Z-up)
- OBJ is Y-up; GLB follows the glTF standard
- Color `#231815`
- Closed mesh, 5 pieces (shell + 4 bangs), ~2,100 triangles

Files: `Hair_03_SleekBob_Handmade.obj` / `.mtl` / `.glb` / `.blend`, `previews/`
